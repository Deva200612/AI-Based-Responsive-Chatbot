About EduBot

🎯

Project Goal

Build an AI-powered chatbot that helps school students get instant answers on curriculum topics using NLP and deep learning.

👥

Target Users

Students of grades 6–12, teachers, and parents who want quick topic-wise explanations and study support.

⚙️

Model Architecture

Double Bidirectional LSTM layers with Embedding + Dropout, trained for 250 epochs with Adam optimizer.

📊

Training Details

250 epochs · Batch size 8 · Vocab 5000 · Max length 20 · Confidence threshold: 50%

Tech Stack

Python 3.x TensorFlow / Keras Bidirectional LSTM NLP Tokenizer Flask REST API Flask-CORS NumPy HTML · CSS · JavaScript

How EduBot Works

1

User Input

Student types a question. Frontend sends a POST request to Flask backend at /chat.

2

Tokenization & Padding

Text is tokenized using Keras Tokenizer (vocab: 5000), padded to max length 20 tokens.

3

BiLSTM Inference

Double Bidirectional LSTM processes the sequence through Embedding → BiLSTM → BiLSTM → Dense layers, outputs softmax probabilities.

4

Confidence Check

If top intent confidence ≥ 50% → matched response. Below threshold → fallback message asking the student to rephrase.

5

Response Sent to Frontend

Flask returns JSON with reply, intent, and confidence. Frontend renders the formatted HTML response with subject badge.
